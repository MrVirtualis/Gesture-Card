# Gesture Card for Home Assistant

A custom Lovelace card that enables gesture-based controls for Home Assistant dashboards.

## Installation

### HACS (Custom Repository)

1. Open HACS in your Home Assistant instance.
2. Click on the three dots in the top right corner and select **Custom repositories**.
3. Add your repository URL, select **Plugin** as the category, and click **Add**.
4. Search for "Gesture Card" and click **Download**.

## Usage

Add the card to your dashboard using the manual card editor:

```yaml
type: custom:gesture-card
